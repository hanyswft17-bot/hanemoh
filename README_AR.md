# هاني سوفت وير — Hani Software

## النسخة المجهزة لـ Supabase
اتبع الخطوات كاملة في `README_SUPABASE_AR.md`.

- مخطط PostgreSQL: `database/schema_supabase.sql`
- الخدمات الأولية: `database/seed_services_supabase.sql`
- استضافة Docker: `Dockerfile` و`render.yaml`
- الاتصال بقاعدة البيانات من متغيرات البيئة (لا ترفع الأسرار إلى GitHub).

هذه الملفات تحتاج إعداد مشروع Supabase ومتغيرات الاستضافة ثم اختباراً فعلياً قبل الإطلاق.

## ما تم تحديثه في واجهة الإصدار الحالي
- واجهة رئيسية جديدة بالأسود والذهبي والأحمر ومتجاوبة مع الهاتف والكمبيوتر.
- شعار SVG قابل للتكبير دون فقدان الجودة: `assets/hani-logo.svg`.
- أقسام تغطي نطاق الخدمات الموسع: شركات الهواتف، FRP وMDM وIMEI وiCloud وFirmware، التراخيص، البوكسات والدونجل، الألعاب وبطاقات الهدايا، وتأجير الأدوات.
- صفحة الخدمات تدعم فتح القسم عبر `?category=`.
- الخدمات الجديدة في `database/seed_extended_catalog.sql` أسعارها صفرية كقوالب أولية؛ يجب ضبط الأسعار الفعلية والتحقق من الموردين قبل عرضها للبيع.

## ملاحظة نطاق التنفيذ
هذه حزمة أساس تشغيلية لواجهة المتجر مع حسابات العملاء والطلبات والمحفظة والشحن ولوحة إدارة الخدمات والطلبات، وليست بعد نظاماً مكتملاً لكل عناصر التصور الكبير. الرتب المتعددة، الموظفون وصلاحياتهم التفصيلية، تحويل الرصيد بين العملاء، ورفع إيصالات الدفع إلى Storage تحتاج مراحل برمجية واختبارات إضافية قبل الإطلاق التجاري.
